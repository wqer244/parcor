# باركور العرب — تجهيز Expo لبناء APK

## ما تم إصلاحه
1. **أول بلوكة كانت مستحيلة فعلياً** — الفجوة بين نقطة البداية وأول منصة كانت أكبر من أقصى مسافة يقدر عليها القفز رياضياً. تم تعديل ثوابت الفيزياء (`services/game3DPhysics.ts`) وتقريب المنصة الأولى، وتم التحقق رياضياً من كل قفزة في المسار (17 قفزة) بما فيها القفزات القطرية.
2. **مشكلة الاتجاه (طول بدل عرض)** — تمت إضافة قفل فعلي لاتجاه landscape وقت التشغيل في `app/_layout.tsx` (عبر `expo-screen-orientation`) بحيث يعمل داخل Expo Go وداخل نسخة الـ APK النهائية أيضاً.
3. **تنظيف المشروع** — تمت إزالة كل الملفات غير المتعلقة بلعبة الموبايل (خادم الويب الخاص بـ Replit، سكربتات البناء القديمة، ملف فيزياء 2D قديم غير مستخدم، مكوّن غير مستخدم)، وتحويل `package.json` من الاعتماد على pnpm monorepo إلى مشروع Expo مستقل بالكامل.

## خطوات البناء إلى APK

### 1) تثبيت الاعتماديات
```bash
npm install
```

### 2) التأكد من إصدار حزمة اتجاه الشاشة (مهم)
أضفت `expo-screen-orientation` بإصدار متوافق مع Expo SDK 54، لكن للتأكد 100% أن الإصدار مطابق تماماً لبيئتك، شغّل:
```bash
npx expo install expo-screen-orientation
```
هذا الأمر يصحح الإصدار تلقائياً إذا لزم الأمر (لن يكرر التثبيت إذا كان صحيحاً أصلاً).

### 3) تثبيت أداة EAS CLI (مرة واحدة فقط على جهازك)
```bash
npm install -g eas-cli
eas login
```
(تحتاج حساب مجاني على expo.dev)

### 4) بناء APK مباشر (سحابياً، بدون Android Studio)
```bash
eas build -p android --profile preview
```
عند الانتهاء ستحصل على رابط تحميل مباشر لملف APK جاهز للتثبيت على أي جهاز أندرويد.

> أول مرة تشغّل هذا الأمر، قد يسألك EAS عن إنشاء مشروع جديد على حسابك — وافق (yes) ليتم ربط `app.json` تلقائياً بمعرّف مشروعك.

### بديل: بناء محلي (يتطلب Android Studio مثبت)
```bash
npx expo run:android
```

## ملاحظة حول Firebase
الإعدادات في `services/firebase.ts` تستخدم Firebase JS SDK (وليس react-native-firebase)، لذلك لا حاجة لملف `google-services.json` أو أي إعداد أندرويد إضافي — يعمل مباشرة داخل Expo managed workflow.
